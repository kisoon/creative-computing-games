## 허용된 실행 보완

- **인술:** p5.js 2.x의 전역 함수와 충돌하는 사용자 함수 `distance`를 `featureDistance`로 바꾸고 호출부만 연결했습니다. 거리 계산식, 인식 수치, 수인 조합, 화면 문구·스타일·효과는 그대로입니다.
- **심판:** 제출된 정적 웹 빌드에서 `bodyPose()`의 비동기 모델 생성 완료를 기다리도록 `await`를 추가했습니다. 원본 화면과 그리기 함수는 변경하지 않았습니다.
- **MD 코드 복원:** 「잡초와 토벌」의 HTML·CSS·JavaScript는 제출된 MD의 해당 코드 블록과 동일합니다. 다른 튜닝 예시 코드를 덮어쓰거나 게임 규칙을 바꾸지 않았습니다.
- **MD 기획 구현:** 「엘사 필터」는 실행 코드가 제출되지 않아 새로 보완한 HTML·CSS·JavaScript 3개입니다. 기획된 13개 효과의 실행과 미리보기를 제공합니다. 실제 관절 데이터의 제스처 판정과 카메라 로딩을 구현했지만, 화면 구성·임계값·이펙트 세부 형태는 이번 보완판의 해석입니다. 학생의 원본 완성 코드와 동일하다는 의미가 아니며 카드와 작품 문서에도 보완 사실을 표시합니다.
