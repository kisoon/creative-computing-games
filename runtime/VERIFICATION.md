# ml5 실행 검증 — 2026-11-23

A·B반 세 번째 바이브 코딩의 실제 추론 작품 18개를 확인했습니다. 찹쌀떡 AR은 ml5 스크립트를 포함하지만 원본부터 클릭 기반이며 추론 작품 수에는 포함하지 않습니다.

## 실행 변경

- 원래 모델 버전과 가중치를 유지하며 모델 파일을 같은 사이트에서 제공합니다. 외부 TF Hub/Kaggle 리다이렉트의 실패와 지연을 줄입니다. 라이브러리 CDN과 일부 WASM은 여전히 외부 연결이 필요합니다.
- 모델 준비를 기다린 뒤 인식을 시작합니다. 원본 영상 크기의 비표시 canvas를 입력으로 사용해 일부 GPU에서 video 입력이 빈 인식을 반복하던 문제를 우회합니다. 좌우 반전 옵션, 좌표, 임계값은 유지합니다.
- 정지·페이지 종료 시 추론과 프레임 갱신을 중단합니다. 준비 중 취소한 인식은 다시 시작하지 않습니다.
- 인술 수련장의 시작 버튼은 핸들러 연결 전 클릭을 막습니다.
- Touchline 손 모델의 실행 엔진은 MediaPipe에서 TFJS로 변경했습니다. 같은 lite 모델과 기존 게임 판정·그림을 유지합니다. 별도 몸 인식은 원래 MediaPipe Pose Landmarker를 유지합니다.

## 확인 범위

macOS Chrome, Apple M2 GPU, 가상 카메라의 손·얼굴·몸 이미지로 실제 모델 결과를 확인했습니다. 18개 작품의 모델 준비와 추론 호출을 점검했고, 손 입력 작품은 손 좌표를, 얼굴 입력 작품은 얼굴 좌표를, MoveNet 작품은 사람 좌표를 반환했습니다. 인술 수련장의 지연 시작 FaceMesh도 별도로 얼굴 1개 반환을 확인했습니다. Touchline의 별도 몸 모델도 신체 일부를 인식해 전신 안내를 표시했고 실행 오류가 없었습니다. [브라우저 검증 결과](browser-results.json)에 콜백과 반환 개수를 기록했습니다. `node runtime/tests/ml5-support.cjs`로 로딩 중 취소·재시작·종료 및 영상 준비 대기 회귀 검사를 통과했습니다.

모델이 사용하는 부위가 없는 시험 영상의 빈 결과는 실패로 취급하지 않습니다.

실제 교실의 조명·카메라·장치별 속도와 모든 게임 진행 경로를 보장하는 검증은 아닙니다. 첫 라이브러리/모델 로딩 및 장치의 추론 시간은 여전히 필요합니다.

그림·스타일·효과·게임 규칙은 변경하지 않았습니다. [integrity.json](integrity.json)은 이번 수정 전후 파일 해시입니다. 이전 제출물 비교의 해시는 각 collection 기록의 baselineSha256에 보존했습니다. 학생용 첫 README에는 개발 설명을 추가하지 않았습니다.
