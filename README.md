## 이용 안내

- 반과 바이브 코딩 차수를 선택해 작품을 찾아보세요.
- 작은 스크린샷이나 실행 버튼을 누르면 새 창에서 열립니다.
- 키보드·카메라 작품은 PC에서 체험해 주세요. 카메라 작품은 권한을 허용해야 합니다.
- 소리가 나지 않으면 작품 화면을 클릭하거나 시작 버튼을 눌러 주세요.

## 작품과 출처

학습과 실험을 위해 제작한 수업 결과물입니다. 작품에서 참고하거나 사용한 이미지·음원·캐릭터 등의 권리는 원저작자에게 있습니다.

출처나 사용과 관련해 살펴볼 부분이 있다면 [의견을 남겨 주세요](https://github.com/kisoon/creative-computing-games/issues/new).
