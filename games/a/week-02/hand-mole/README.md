# 손 인식 두더지 잡기

웹캠으로 손을 인식해서 플레이하는 두더지 잡기 게임입니다.
**편 손**으로 뿅망치를 움직이고, **주먹을 쥐는 순간** 그 자리를 내리칩니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 뼈대 + p5.js / ml5.js + 스타일(CSS)까지 포함 |
| `sketch.js` | 게임 로직 + 손 인식 + 주먹 판정 |
| `style.css` | 예전 스타일 파일 (지금은 index.html에 포함되어 있어 **없어도 됨**) |
| `fist-hit-detection.md` | 주먹 타격 판정 설계 명세 |

## ml5 에디터에서 실행하기 (탭 2개만)

1. <https://editor.ml5js.org> 접속
2. 왼쪽 파일 목록에서 `index.html` 선택 → 이 폴더의 `index.html` 내용으로 전체 교체
3. `sketch.js` 선택 → `sketch.js` 내용으로 전체 교체
4. 실행(▶) 버튼 → 브라우저가 카메라 권한을 요청하면 **허용**

> `style.css` 파일이 없는 에디터도 있습니다. 스타일은 `index.html` 안에 들어 있어서
> `style.css`는 **필요 없습니다.** (탭에 있으면 그대로 두거나 비워도 됩니다.)

> 모델을 처음 불러올 때 몇 초 걸립니다. "손 인식 모델 준비 완료"가 뜨면 시작할 수 있어요.

## 조작

| 동작 | 게임에서 |
|---|---|
| 손 펴기 (보) | 뿅망치가 손을 따라 이동 |
| 주먹 쥐기 | 그 자리에서 1회 타격 |
| 주먹 유지 | 추가 타격 없음 (손을 폈다가 다시 쥐어야 함) |
| 마우스 | 커서 이동 + 클릭으로 타격 (카메라 없을 때) |
| 클릭 / Space | 시작 · 재시작 |
| R | 재시작 |
| D | 디버그 패널 표시/숨김 |

## 게임 규칙

- 제한 시간 **30초**, 구멍 **9개**
- 두더지가 랜덤한 구멍에서 올라옴 (후반으로 갈수록 빨라짐)
- 맞히면 +1점, 콤보 증가
- 놓치거나 빈 곳을 치면 콤보 초기화
- 한 번의 타격으로 두더지는 최대 1마리

## 손 인식이 잘 안 될 때

1. 디버그 패널의 **SPREAD** 값을 확인하세요.
   - 손을 폈을 때 1.2 이상, 주먹을 쥐었을 때 0.8 이하로 나오면 정상
2. 값이 다르면 `sketch.js` 맨 위 `CFG`에서 조정:

```js
FIST_ENTER: 0.85,   // 이 값보다 작으면 주먹 (타격이 안 되면 ↑)
OPEN_ENTER: 1.15,   // 이 값보다 크면 편 손 (주먹이 편 손으로 오인되면 ↑)
FIST_EXIT: 1.00,    // 주먹에서 편 손으로 복귀하는 값
FIST_CONFIRM_FRAMES: 3,  // 오타격이 잦으면 4~5로
HIT_COOLDOWN_MS: 300,    // 연타가 필요하면 200까지
```

3. 카메라 앞 **40~80cm**, 손바닥이 카메라를 향하게, 조명은 정면에서.
4. 손이 화면 밖으로 나가면 인식이 끊깁니다. 상체가 화면에 들어오게 앉으세요.

## 로컬에서 실행

```bash
python3 -m http.server 8765
```

브라우저에서 <http://localhost:8765> 접속.
(카메라는 `https` 또는 `localhost`에서만 허용됩니다. `file://`로 직접 열면 카메라가 막힐 수 있어요.)

## 판정 방식 요약

자세한 내용은 `fist-hit-detection.md` 참고.

- 손 크기로 정규화한 `spread` 값으로 편 손/주먹 판정
- 진입/이탈 임계값을 분리한 히스테리시스
- 주먹 3프레임 연속 확인 + 300ms 쿨다운
- **편 손 → 주먹으로 바뀌는 에지에서만** 타격
- 타격 좌표는 주먹 직전 편 손 3프레임의 중앙값
