# 🍎 손바닥 과일 받기 (ml5.js handPose)

웹캠으로 손바닥을 인식해서 바구니를 움직이고, 떨어지는 과일을 받는 미니 게임입니다.
p5.js + ml5.js(`handPose`)만으로 만들었고 이미지 파일 없이 이모지로 그립니다.

## 실행 방법

카메라 권한 때문에 `file://`로 열면 동작하지 않습니다. **로컬 서버**로 열어 주세요.

```bash
cd "Documents/기본 프로젝트"
bash start.sh
```

또는 직접 서버를 띄워도 됩니다.

```bash
# Python3가 동작하는 경우
python3 -m http.server 8000

# Python3가 없을 때 (macOS 기본 Ruby, 한글 경로는 UTF-8 로케일 필요)
LANG=en_US.UTF-8 ruby -run -e httpd -- . -p 8000
```

그다음 브라우저에서 <http://localhost:8000> 접속 → 카메라 권한 허용 → **화면 클릭**해서 시작.

- Chrome / Edge / Safari 최신 버전 권장
- 모델을 CDN에서 받아오므로 인터넷 연결 필요
- **접속하면 카메라를 자동으로 켭니다** (권한 팝업 허용)
- 카메라가 없거나 권한을 거부해도 **마우스로 플레이 가능** (자동 전환)
- 카메라 권한을 허용한 뒤 인식이 안 되면 **R 키** 또는 화면 클릭으로 재연결

> ⚠️ OpenCode의 미리보기(Review) 브라우저는 카메라 권한이 차단되어 있습니다(확인됨).
> 그럴 때는 Chrome/Safari에서 <http://localhost:8000>을 직접 열어 주세요.

## 카메라가 안 될 때

먼저 **진단 페이지**를 Chrome에서 열어 주세요.

<http://localhost:8000/camera-test.html>

- `permission` 값과 오류 이름(`NotAllowedError` 등)이 그대로 표시됩니다.
- `카메라 다시 테스트` 버튼으로 재시도할 수 있습니다.

> **가장 흔한 원인:** 주소창이 `file:///Users/...`로 시작하면(파일 더블클릭)
> Chrome·Safari 모두 카메라를 차단합니다. 반드시 `bash start.sh` 실행 후
> 주소창에 `file://`이 **아닌** `http://localhost:8000`을 직접 입력하세요.

| 증상 | 해결 |
| --- | --- |
| 주소가 `file:///...` | 파일 더블클릭 금지 → `bash start.sh` 후 `http://localhost:8000` 접속 |
| 권한 거부(`NotAllowedError`) | 주소창의 카메라 아이콘 → 허용 → **R** |
| 아무 반응 없음 | `file://`이 아닌 `http://localhost:8000`인지 확인 |
| 다른 앱이 사용 중 | 화상회의 앱 종료 후 **R** |
| 계속 권한 거부 | `chrome://settings/content/camera`에서 localhost 차단 해제 |
| Chrome에서만 안 됨 | macOS **시스템 설정 → 개인정보 보호 및 보안 → 카메라**에서 Google Chrome 켜기 |
| 손이 인식 안 됨 | 밝은 곳, 손바닥 전체가 화면에 보이게, 30–60cm 거리 |
| 미리보기 창에서만 안 됨 | Chrome/Safari에서 직접 접속 |

## 게임 규칙

- 손바닥(또는 마우스)을 움직여 바구니를 조작
- 과일을 받으면 +1점, 놓치면 목숨 -1
- 폭탄 💣 을 받아도 목숨 -1
- 목숨 3개가 모두 사라지면 게임 끝, 최고 점수는 `localStorage`에 저장
- 시작 화면과 게임 중 상단에 **카메라 상태**(연결 중 / 준비 완료 / 오류)가 표시됩니다

## 손 인식 방식

`ml5.handPose()`가 돌려주는 21개 손 관절 중
**손목(0) + 손가락 뿌리(5, 9, 13, 17)** 의 평균을 손바닥 중심으로 사용합니다.
웹캠 영상과 좌표를 거울처럼 보이도록 x축을 반전해서 그립니다.

## 쉽게 바꿔 보는 값

| 위치 | 의미 |
| --- | --- |
| `FRUITS` 배열 | 등장하는 과일 이모지 |
| `basket.w` | 바구니 폭 (판정 범위) |
| `spawnInterval` | 과일 생성 간격 (작을수록 어려움) |
| `fallSpeed` | 낙하 속도 |
| `0.07 + score * 0.007` | 폭탄 등장 확률 |
| `lives = 3` | 목숨 개수 |
