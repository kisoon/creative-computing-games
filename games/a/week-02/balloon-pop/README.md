# 하늘빛 풍선 팡팡 🎈

p5.js와 ml5.js의 `handPose`를 사용해 만든 손 인식 풍선 터뜨리기 게임입니다.

- 손가락 끝 5곳(엄지·검지·중지·약지·새끼)이 풍선에 닿으면 `팡!`
- 하늘 배경 위로 여러 색의 풍선이 리듬을 타고 떨어집니다.
- **카메라에 손이 실제로 인식된 뒤에만 "게임 시작" 버튼이 활성화됩니다.**
- 손이 인식되지 않거나 카메라 권한이 없으면 게임을 시작할 수 없습니다.
- 빠르게 연속으로 터뜨리면 콤보 보너스 점수
- 풍선을 바닥으로 떨어뜨리면 하트 1개 감소, 하트 3개를 모두 잃으면 게임 오버
- 최고 점수는 브라우저 `localStorage`에 저장

## 실행 방법

카메라 권한 때문에 `file://`로 바로 열면 동작하지 않을 수 있습니다. 아래처럼 로컬 서버로 열어 주세요.

```bash
cd 창의컴퓨팅_week13
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 접속 → 카메라 권한 허용.

> Python이 없다면 macOS에 기본 포함된 Ruby로도 됩니다.
>
> ```bash
> LANG=en_US.UTF-8 ruby -run -e httpd . -p 8000
> ```
>
> VS Code의 **Live Server** 확장을 사용해도 됩니다.

Chrome / Edge / Safari 최신 버전 권장. 처음 실행 시 손 인식 모델을 내려받기 때문에 몇 초 걸릴 수 있습니다.

## 게임 시작 조건

1. 페이지를 열면 카메라 권한을 요청합니다. **허용**을 눌러 주세요.
2. 손 인식 모델이 준비될 때까지 기다립니다.
3. 카메라 앞에 손바닥을 펴서 보여 주세요.
4. 상태 카드가 **"손 인식 완료!"** 로 바뀌면 **게임 시작** 버튼이 활성화됩니다.
5. 버튼을 누르면 게임이 시작됩니다.

손을 카메라에서 치우면 시작 버튼이 다시 비활성화됩니다. 게임 오버 후 **다시 도전** 버튼도 같은 방식으로 손이 보여야 합니다.

## 조작

| 동작 | 효과 |
| --- | --- |
| 손끝을 풍선에 대기 | 풍선 터짐 (+점수) |
| 카메라 앞에서 손을 움직이기 | 화면의 조준점과 손끝이 함께 움직임 |
| `게임 시작` / `다시 도전` 버튼 | 손 인식 상태일 때만 게임 시작 |

## 파일 구성

```
index.html   # p5.js / ml5.js 로드, 시작·결과 화면, 상태 UI
style.css    # 하늘빛 디자인, 반응형 4:3 화면, 버튼/상태 애니메이션
sketch.js    # 손 인식, 하늘 배경, 풍선, 충돌, HUD, 사운드 전체
```

## 동작 원리 메모

- `ml5.handPose({ maxHands: 1, flipHorizontal: true })`
  - `flipHorizontal: true`는 거울 모드로 보여 주는 웹캠 화면과 손끝 좌표를 일치시킵니다.
- `handPose.detectStart(video, gotHands)`로 매 프레임 손 인식 결과를 받습니다.
- `gotHands()`에서 손이 감지된 시각을 기록하고, **0.28초 이상 안정적으로 감지 + 현재 손이 보이거나 최근 0.25초 이내 감지**일 때만 시작 버튼을 활성화합니다.
- 풍선 충돌은 손가락 끝 5개의 좌표와 풍선 중심 거리를 비교해 판정합니다.
- 카메라 영상은 화면을 가리지 않도록 왼쪽 아래 **HAND CAM** 미리보기로 표시하고, 손 뼈대와 손끝 조준점은 게임 화면 위에 바로 그립니다.
- 모든 그래픽은 p5.js로, 효과음은 외부 파일 없이 WebAudio 오실레이터로 만듭니다.

## 조정해 볼 만한 값

`sketch.js` 상단/내부 상수만 바꿔도 난이도와 느낌을 바꿀 수 있습니다.

| 값 | 위치 | 설명 |
| --- | --- | --- |
| `BALLOON_COLORS` | 상단 | 풍선 색 팔레트 (base/dark 쌍 추가·삭제) |
| `MAX_LIVES` | 상단 | 목숨 개수 |
| `FINGERTIP_RADIUS` | 상단 | 손끝 판정 반경 (클수록 쉬움) |
| `spawnInterval` | `updateGame()` | 풍선 생성 간격 (작을수록 어려움) |
| `speedBoost` | `spawnBalloon()` | 시간이 지날수록 빨라지는 정도 |
| `14` | `updateGame()` | 화면에 동시에 존재하는 풍선 최대 개수 |
| `clouds` | `buildSky()` | 구름 개수·크기·속도 |

## 참고

- 카메라 권한을 거부했다면 주소창의 카메라 아이콘에서 권한을 허용한 뒤 새로고침해 주세요.
- 카메라 영상은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.
- 손 인식 모델과 p5.js/ml5.js 라이브러리는 CDN에서 불러오므로 인터넷 연결이 필요합니다.
