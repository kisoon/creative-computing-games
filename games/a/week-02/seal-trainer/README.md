# 印 · 인술 트레이너 (Ninjutsu Hand Seal Trainer)

12지신 **인(印)** 을 손 관절로 인식하고, **정해진 순서**가 맞으면 인술 이펙트가 발동하는 웹 MVP입니다.

- **치도리** — 소 → 토끼 → 원숭이 · 오른손에 전기 응집
- **호화구의 술법** — 뱀 → 염소 → 원숭이 → 돼지 → 말 → 호랑이 · 입을 벌리면 화염
- **분신술** — 염소 → 뱀 → 호랑이 · 좌우로 분신 생성

## 실행

```bash
cd 11
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 → **카메라로 시작** → 우측 상단 **12인 학습**.

> 카메라는 `localhost` 또는 `https`에서만 열립니다. Chrome 기준으로 테스트했습니다.
> ml5.js/p5.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 사용법

1. **12인 학습** — 인을 맺고 3초 기다리면 자동으로 관절 샘플 5개를 저장합니다. 인마다 1회씩.
2. **인 맺기** — 인을 0.5초 정도 유지하면 상단에 기록됩니다.
3. **발동** — 레시피 순서가 정확히 완성되면 인술이 나갑니다.

학습 데이터는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.

### 데모 모드

카메라 없이 연출만 확인할 수 있습니다. 시작 화면에서 **데모 모드** 선택 후 키보드로 인을 입력합니다.

| 키 | 인 | 키 | 인 |
|---|---|---|---|
| 1 | 쥐 | 8 | 염소 |
| 2 | 소 | 9 | 원숭이 |
| 3 | 호랑이 | 0 | 닭 |
| 4 | 토끼 | Q | 개 |
| 5 | 용 | W | 돼지 |
| 6 | 뱀 | H | 관절 표시 토글 |
| 7 | 말 | Esc | 패널 닫기 |

예) 치도리: `2 → 4 → 9`

URL 파라미터로 자동 시연도 가능합니다: `?demo=chidori`, `?demo=fireball`, `?demo=clone`

## 인식 방식

12인은 손가락이 서로 가려 **범용 사전학습 모델로 12개를 직접 분류하기 어렵습니다.** 그래서 이 MVP는 **사용자 캘리브레이션 + kNN**을 씁니다.

```
웹캠 → ml5.handPose (21 관절 × 2손)
     → 손목 기준 이동·손바닥 크기로 스케일 정규화
     → 학습된 인 샘플과의 평균 관절 거리 비교 (좌/우 손 순서 뒤집힘 허용)
     → 6프레임 + 0.28초 이상 안정되면 인 확정
     → 최근 인 시퀀스의 접미사와 레시피 비교
     → 일치 시 이펙트
```

- 왼손/오른손 순서는 x좌표로 정렬하고, 거리 계산 시 두 순열을 모두 시도합니다.
- 한 손만 인식된 경우에도 비교가 가능하도록 손 개수 불일치에 패널티만 부여합니다.
- 인식 거리(`d`)는 화면 하단에 표시됩니다. 잘못 인식되면 해당 인을 다시 학습하세요.

## 이펙트 구현

| 인술 | 구현 |
|---|---|
| 치도리 | 중점 변위(midpoint displacement)로 생성한 번개 + 가산 광원 + 스파크 파티클 |
| 호화구 | FaceMesh 13·14번 랜드마크(윗입술·아랫입술) 거리로 입 벌림 판정 → 화염 제트 + 입자 |
| 분신술 | 현재 프레임을 스냅샷 → 좌우 오프셋 반투명 복사 + 연기 |

## 튜닝

`sketch.js` 상단 상수:

```js
const RECOG_THRESHOLD = 0.27; // 낮추면 엄격, 높이면 관대
const STABLE_FRAMES = 6;
const STABLE_MS = 280;
const TRAIN_SAMPLES = 5;
```

- 오인식이 잦으면 `RECOG_THRESHOLD`를 0.20~0.23으로 낮추세요.
- 인식이 너무 안 되면 0.30까지 올리거나 조명을 개선하세요.
- 샘플이 부족하면 각 인을 다시 학습하세요.

## 한계

- 두 손이 겹치는 인은 MediaPipe가 손가락 일부를 놓칠 수 있습니다. **학습과 플레이를 같은 조명·거리에서** 하는 것이 가장 중요합니다.
- 12인 중 비슷한 손 모양은 오분류가 날 수 있습니다. 그 경우 해당 인만 재학습하거나 `RECOG_THRESHOLD`를 조정하세요.
- 카메라가 없으면 인식은 동작하지 않습니다(데모 모드로 연출만 확인 가능).
- `file://`로 직접 열면 카메라가 막힐 수 있으니 로컬 서버를 사용하세요.
