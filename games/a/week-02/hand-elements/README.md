# 손바닥 원소 · Hand Elements

웹캠으로 손을 인식해 손바닥에 불·물·번개·얼음을 소환하고, 손바닥을 펼쳐 발사하는 p5.js + ml5.js 인터랙션 아트입니다.

## 실행 방법

### 1) 더블클릭 (가장 간단)

`start.command` 파일을 더블클릭하세요.
로컬 서버(`http://localhost:8000`)가 켜지고 브라우저가 자동으로 열립니다.
카메라 권한을 허용하면 바로 시작됩니다.

> macOS에서 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면,
> 파일을 우클릭 → **열기**를 선택하거나 터미널에서 아래 명령을 실행하세요.
>
> ```bash
> chmod +x start.command
> ./start.command
> ```

### 2) 터미널

프로젝트 폴더에서:

```bash
ruby -run -e httpd . -p 8000
```

그 다음 브라우저에서 <http://localhost:8000> 을 엽니다.

### 3) VS Code

Live Server 확장으로 `index.html`을 열어도 됩니다.

> **중요:** 카메라는 `file://`이 아니라 `http://localhost` 주소에서 열어야 안정적으로 동작합니다.
> p5.js, ml5.js, 손 인식 모델을 CDN에서 내려받으므로 첫 실행 시 인터넷 연결이 필요합니다.

## 조작 방법

| 동작 | 결과 |
| --- | --- |
| 엄지 + 검지 끝 맞대기 | 🔥 불 |
| 엄지 + 중지 끝 맞대기 | 💧 물 |
| 엄지 + 약지 끝 맞대기 | ⚡ 번개 |
| 엄지 + 새끼 끝 맞대기 | ❄️ 얼음 |
| 주먹 쥐기 | 원소 해제 |
| 손바닥 펼치기 | 손이 향한 방향으로 발사 |

- 양손을 동시에 인식합니다.
- 얼음 상태에서는 손등 뒤로 얼음 기둥이 솟아오릅니다.
- 손이 화면 밖으로 나가면 발사가 멈춥니다.

## 파일 구성

```
index.html     화면 레이아웃, 로딩 오버레이, p5/ml5 로드
sketch.js      손 인식 + 원소 파티클 아트 (메인 스케치)
start.command  로컬 서버 + 브라우저 실행 스크립트
README.md      이 문서
```

## 인식이 잘 안 될 때

`sketch.js` 상단의 값들을 조절해 보세요.

```js
const OPEN_EXTEND = 1.55;  // 손가락을 펼친 정도 (발사 판정)
const OPEN_SPREAD = 1.45;  // 손가락 사이가 벌어진 정도
const OPEN_THUMB  = 0.55;  // 엄지가 벌어진 정도
```

- 발사가 너무 쉽게/어렵게 되면 `OPEN_EXTEND`, `OPEN_SPREAD`를 조절합니다.
- 엄지와 손가락을 맞대는 판정 범위는 `track()` 안의 `this.palmSize * 0.35` 값을 바꿉니다.
- 밝은 조명에서 손 전체가 화면에 들어오도록 하는 것이 가장 중요합니다.

## 참고

- 원본 스케치에서 실행 환경에 맞게 다음을 보완했습니다.
  - `createCanvas(640, 480).parent('frame')` — 캔버스를 화면 프레임 안에 배치
  - `await handPose.ready` — ml5 1.4의 `handPose()`는 인스턴스를 즉시 반환하므로, 모델이 실제로 준비된 뒤 손 인식을 시작하도록 수정 (원본 코드에서는 모델 로딩 전에 감지 루프가 시작되어 손 인식이 동작하지 않을 수 있음)
  - `draw()` 첫 줄의 카메라 준비 가드 — 모델/카메라 로딩 중 첫 프레임 오류 방지
- 첫 실행은 손 인식 모델을 내려받은 뒤 카메라 권한을 요청합니다. 로딩 오버레이가 사라질 때까지 기다려 주세요.
- 해상도는 640×480, 손 인식은 ml5의 경량 모델(`lite`)을 사용합니다.
