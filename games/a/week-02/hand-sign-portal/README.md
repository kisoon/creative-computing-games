# HAND SIGN PORTAL

ml5.js **HandPose**와 **FaceMesh**로 만든 실시간 손짓 비주얼 아트 웹 실험입니다.
엄지와 검지를 맞대면 손끝 사이에 유기적인 **포탈(도형)**이 열리고, 나머지 세 손가락의 모양으로 포탈 안의 필터가 바뀝니다. 포탈은 손을 따라 움직이고, 크기는 손과 카메라의 거리에 따라 자연스럽게 달라집니다.

- 손 21개 키포인트 → 핀치·손가락 펴짐 판정
- 5가지 실시간 캔버스 필터: 네거티브 / 글리치 / 픽셀화 / 모노크롬 / 얼굴 왜곡
- 얼굴 왜곡은 FaceMesh 468 랜드마크 + 852개 삼각 메쉬를 실시간으로 변형
- 카메라 없이 볼 수 있는 **데모 모드**와 필터 미리보기
- 모든 처리는 브라우저 안에서만. 영상은 서버로 전송되지 않습니다.

---

## 실행 방법

카메라는 `https://` 또는 `localhost`에서만 열립니다. `index.html`을 더블클릭(`file://`)하면 카메라가 차단되니, 아래처럼 로컬 서버로 열어 주세요.

```bash
cd "10조"
python3 -m http.server 8000
```

브라우저에서 **http://localhost:8000** 을 엽니다.

> Node가 있다면 `npx serve .` 도 됩니다.
> 웹캠 권한을 허용하면 잠시 후 손 인식 모델이 로드됩니다. 첫 로드에는 모델 다운로드 때문에 몇 초가 걸릴 수 있습니다.

카메라가 없거나 권한을 주고 싶지 않다면 시작 화면의 **카메라 없이 미리보기**를 누르세요. 추상적인 데모 화면 위에서 5가지 필터를 모두 확인할 수 있습니다.

## 조작법

### 기본 제스처

1. **엄지 + 검지 끝을 맞댑니다(핀치).** → 포탈이 열립니다.
2. **중지 · 약지 · 새끼 손가락을 펴고 접어** 필터를 고릅니다.
3. 손을 움직여 포탈의 위치와 크기를 조절합니다.
4. 핀치를 풀면 포탈이 닫힙니다.

### 필터 선택표

엄지와 검지는 핀치에 사용하므로, 필터는 **중지(M) · 약지(R) · 새끼(P)** 세 손가락의 조합으로 정합니다.

| 필터 | 중지 | 약지 | 새끼 | 손 모양 |
|---|---|---|---|---|
| **네거티브** `NEGATIVE` | ✊ | ✊ | ✊ | 핀치만 (나머지 접기) |
| **글리치** `GLITCH` | ☝️ | ☝️ | ✊ | 중지 + 약지 펴기 |
| **픽셀화** `PIXELATE` | ✊ | ☝️ | ☝️ | 약지 + 새끼 펴기 |
| **모노크롬** `MONOCHROME` | ☝️ | ☝️ | ☝️ | 세 손가락 모두 펴기 |
| **얼굴 왜곡** `FACE WARP` | ☝️ | ✊ | ☝️ | 중지 + 새끼 (락 사인) |

- 얼굴 왜곡은 카메라에 얼굴이 보여야 활성화됩니다. 포탈을 얼굴 위로 옮기면 얼굴 메쉬가 물결처럼 일그러집니다.
- 손가락 판정에는 히스테리시스가 있어 경계에서 깜빡임이 줄어듭니다.
- 포탈의 필터는 손가락 모양이 약 0.14초 안정되면 바뀝니다.

### 키보드 · 버튼

| 입력 | 동작 |
|---|---|
| `1` ~ `5` | 해당 필터를 9초간 미리보기 |
| `S` | 스크린샷 PNG 저장 |
| `M` | 소리 켜기/끄기 |
| `F` | 전체 화면 |
| 하단 필터 카드 클릭 | 필터 미리보기 (카메라 없이도 가능) |

우측 상단의 아이콘 버튼으로도 소리 · 스크린샷 · 전체 화면 · 도움말을 사용할 수 있습니다.

## 동작 원리

```
웹캠 ──> ml5.handPose.detectStart()
          └─ 21 keypoints
               ├─ thumb tip(4) ↔ index tip(8) 거리 → 핀치 / 포탈 크기
               ├─ wrist(0) 기준 tip/pip 거리 비율 → 손가락 펴짐
               └─ portal center / radius / rotation 스무딩
                    └─ canvas clip → 필터 렌더러

필터 렌더러 (offscreen canvas)
  negative   : difference 합성으로 색 반전
  glitch     : 수평 슬라이스 찢김 + 색수차 + 컬러 블록
  pixel      : 저해상도 버퍼를 nearest-neighbor 업스케일
  mono       : 휘도 + 콘트라스트 + 4단계 포스터라이즈
  face       : FaceMesh 468점 / 852 삼각형 아핀 워프 + 페더 마스크
```

- 포탈은 필터가 적용된 **같은 프레임**을 도형으로 잘라 보여주는 "창"입니다. 그래서 손이 움직여도 배경과 위화감 없이 따라옵니다.
- 손끝 두 점을 기준으로 포탈 중심·회전·반지름을 계산하고, 지수 스무딩으로 떨림을 줄입니다.
- 얼굴 왜곡은 FaceMesh 결과를 0.62배 해상도의 오프스크린 캔버스에 삼각형 단위로 다시 그린 뒤, 타원형 페더 마스크로 붙입니다. 메쉬 경계의 이음새를 숨기기 위한 처리입니다.
- 얼굴 모델은 얼굴 왜곡 필터를 처음 사용할 때 지연 로드되고, 5초 이상 쓰지 않으면 자동으로 멈춰 CPU를 아낍니다.

## 커스터마이즈

### 필터 추가 / 이름 변경

`js/app.js`의 `FILTERS` 배열을 수정합니다. `pattern`은 `[중지, 약지, 새끼]` 순서의 0/1 문자열입니다.

```js
{
  id: "negative",
  ko: "네거티브",
  en: "NEGATIVE",
  accent: "#ff4d6d",
  pattern: "000",
  hint: "중지 · 약지 · 새끼 접기",
}
```

새 필터를 추가하려면:

1. `FILTERS`에 항목을 추가하고 `PATTERN_INDEX`에 패턴을 등록
2. `js/effects.js`의 `render()` switch에 `case` 추가
3. `renderMyFilter(ctx, src, time)` 구현 후 `return this.out`
4. 하단 범례는 자동으로 늘어납니다. (모바일에서는 카드가 좁아질 수 있음)

### 민감도 · 크기 조절

`js/app.js` 상단:

```js
const PINCH_ENTER = 0.55;   // 작을수록 더 정확히 맞대야 열림
const PINCH_EXIT  = 0.95;   // 클수록 쉽게 닫히지 않음
const SIGN_STABLE_MS = 140; // 손가락 모양 안정 시간
```

포탈 크기는 `updateGesture()`의 `scale * 2.45`(손 크기 대비)와 `updatePortal()`의 `minDim * 0.3`(미리보기)에서 조절합니다.

### 얼굴 왜곡 강도

`js/effects.js`의 `displaceFace()`에서:

- `amp`: 물결 왜곡의 진폭
- `sx`, `sy`: 전체 늘이고 줄이기
- `eyeZoom`: 눈 확대/축소
- jaw 파트: 입·턱 늘이기

값을 키우면 더 과격한 펀하우스 미러가 됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "카메라를 열 수 없습니다" | `http://localhost:8000`으로 열었는지 확인. `file://`은 카메라 불가 |
| 권한 팝업이 안 뜸 | 주소창의 자물쇠/카메라 아이콘 → 권한 허용, macOS 시스템 설정도 확인 |
| 손이 인식되지 않음 | 손 전체(손목 포함)가 화면에 보이게 하고, 조명을 밝게 |
| 포탈이 너무 크거나 작음 | 카메라와의 거리를 조절하거나 위 민감도/크기 상수 수정 |
| 얼굴 왜곡이 안 됨 | 얼굴이 화면에 보이고, 포탈이 얼굴을 덮도록 이동. 첫 사용 시 모델 로딩 몇 초 필요 |
| 버벅임 | 다른 탭/앱을 닫거나, `effects.js`의 `warpScale`을 0.5로 낮춤 |

### 디버그 모드

`http://localhost:8000/?debug` 로 열면 `window.HandSignPortal`이 노출됩니다. 카메라 없이 가짜 키포인트로 상호작용을 테스트할 수 있습니다.

```js
const k = [...]; // 21개의 {x, y} (비디오 원본 좌표)
setInterval(() => window.HandSignPortal.feedHand(k), 70);
```

`?debug` 없이 배포하면 이 훅은 생성되지 않습니다.
