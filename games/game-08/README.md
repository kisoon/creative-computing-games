# 물불 원정대 · Elemental Duo

두 명이 한 키보드에서 물 캐릭터와 불 캐릭터를 각각 조작하는 **2인 협동 횡스크롤 스테이지 MVP**입니다.

하나의 고정 화면 스테이지에서 두 원소가 서로 다른 환경에 반응하며, 각자의 성소를 동시에 밟아 봉인을 해제하고 각자의 출구로 도착하면 클리어됩니다.

## 실행 방법

별도 설치나 빌드 과정이 없습니다.

- `index.html`을 브라우저에서 바로 엽니다.
- 또는 프로젝트 폴더에서 간단한 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

> 로컬 서버가 실행되지 않는 환경이라면 `index.html` 더블클릭으로 실행해도 됩니다. 외부 라이브러리, 이미지, 사운드 파일을 사용하지 않습니다.

## 조작

| 플레이어 | 캐릭터 | 이동 | 점프 |
| --- | --- | --- | --- |
| P1 | 물 | `A` / `D` | `W` |
| P2 | 불 | `←` / `→` | `↑` |

| 키 | 기능 |
| --- | --- |
| `R` | 스테이지 즉시 재시작 |
| `M` | 사운드 켜기 / 끄기 |

## 게임 규칙

1. 물 캐릭터는 **물 웅덩이에서 안전**하고, 불 웅덩이에 닿으면 죽습니다.
2. 불 캐릭터는 **불 웅덩이에서 안전**하고, 물 웅덩이에 닿으면 죽습니다.
3. 화면 중앙의 거대한 봉인문은 잠겨 있습니다.
4. 각 웅덩이 안에는 P1 / P2 전용 성소(압력판)가 있습니다.
5. 두 성소를 **동시에** 밟으면 봉인문이 영구히 열립니다.
6. 두 캐릭터가 각자의 출구에 도착하면 스테이지 클리어입니다.

죽은 캐릭터는 잠시 후 시작 지점에서 부활합니다. 봉인문이 이미 열렸다면 다시 열 필요 없이 출구로 향하면 됩니다.

## 스테이지 흐름

- 왼쪽 시작 지점에서 두 캐릭터가 함께 출발합니다.
- 불 캐릭터는 첫 번째 물 웅덩이를 점프로 넘어야 합니다.
- 물 캐릭터는 두 번째 불 웅덩이를 점프로 넘어야 합니다.
- 각자 자신의 웅덩이 안 성소에 동시에 서면 봉인문이 열립니다.
- 열린 문을 통과해 오른쪽의 물 / 불 출구로 각각 들어갑니다.

## 구현 포인트

- **고정 1스테이지**: 1280×720 논리 해상도, 16:9 반응형 캔버스
- **2인 로컬 플레이**: 완전히 분리된 입력과 캐릭터 상태
- **플랫포머 이동**: 가속/감속, 가변 점프, 코요테 타임, 점프 버퍼
- **AABB 충돌**: 바닥, 좌우 벽, 닫힌 봉인문
- **원소 상호작용**: 웅덩이별 안전/치사 판정, 사망·부활 연출
- **협동 퍼즐**: 두 압력판을 동시에 유지해야 열리는 봉인문
- **승리 조건**: 두 캐릭터가 각자의 출구에 모두 도착
- **피드백**: 화면 흔들림, 파티클, 합성 사운드, 목표/HUD, 클리어 화면
- 외부 에셋 없이 Canvas 2D와 WebAudio만 사용

## 파일 구조

```text
index.html          게임 페이지
style.css           화면 프레임 및 배경 스타일
src/
  core.js           상수, 수학 헬퍼, 사운드, 파티클
  level.js          고정 스테이지 데이터
  game.js           플레이어 물리, 상호작용, 게임 상태
  draw-world.js     배경, 바닥, 웅덩이, 봉인문, 출구
  draw-actors.js    물·불 캐릭터 렌더링
  draw-hud.js       HUD, 토스트, 클리어 화면
  main.js           캔버스 설정, 입력, 게임 루프
```

## MVP 범위

- 메뉴, 스테이지 선택, 저장 기능은 포함하지 않습니다.
- 한 장면의 스테이지와 핵심 이동·충돌·협동 메커니즘에 집중합니다.
- 모바일 터치 조작은 지원하지 않으며, 2인 키보드 플레이를 기준으로 합니다.
